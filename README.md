# FGG — Fast Global Translator

FGG (Fast Global Translator) — это автоматический переводчик игровых локализаций, предназначенный для быстрого и безопасного перевода текстовых файлов с сохранением структуры, тегов и игровых переменных.

---

##  Возможности

* Автоматический перевод игровых файлов на множество языков
* Сохранение структуры `ключ = "текст"`
* Защита игровых плейсхолдеров и тегов
* Поддержка продолжения после остановки (resume)
* Многопоточная обработка для высокой скорости
* Повторные попытки при ошибках перевода
* Режим тестирования (например, 1000 строк)

---

##  Для чего используется FGG

FGG подходит для перевода:

* Модов и игровых сборок
* Файлов локализации
* Диалогов NPC
* Квестов и сценариев
* Описаний предметов
* UI текста
* Любых текстовых ресурсов игр

##  Поддержка игровых тегов

FGG не ломает игровые конструкции.

### Пример:

```text
door_message = "Закройте {clr:red}дверь{clr/}"
```

После перевода:

```text
door_message = "Schließen Sie {clr:red}Tür{clr/}"
```

 Теги сохраняются
 Плейсхолдеры остаются на месте
 Игра продолжает работать корректно

##  Быстрый запуск

### Немецкий язык:

```powershell
python D:\FGG\final_translator.py --langs de
```

---

## Быстрый режим (рекомендуется)

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

---

##  Максимально быстрый режим

```powershell
python D:\FGG\final_translator.py --langs de --workers 15 --request-delay 0 --max-retries 2 --retry-delay 1
```

Может давать ошибки при перегрузке API

python D:\FGG\final_translator.py --langs de --input D:\FGG\оригинал\test_1000_ru.txt --output-dir D:\FGG\переводы_тест --force --workers 10 --request-delay 0

---

##  Основные параметры

### `--langs`

Языки перевода

```text
--langs de en fr
```

---

### `--workers`

Количество потоков

* 5 → стабильно
* 10 → баланс
* 15 → быстро, но риск ошибок

---

### `--request-delay`

Задержка между запросами

* 0 → максимум скорости
* 0.3 → стабильнее
* 1 → максимально надёжно

---

### `--force`

Полный перерасчёт переводов

---

### `--input`

Путь к исходному файлу

---

### `--output-dir`

Папка для результата

---

##  Особенности работы

* Автоматически пропускает уже переведённые строки
* Создаёт `.failed.txt` при ошибках
* Поддерживает восстановление после прерывания
* Использует параллельную обработку
* Сохраняет формат ключей

---

##  Проверка результата

Открыть:

```text
D:\FGG\переводы\de.txt
```

Проверить:

* ключи не изменились
* текст переведён
* теги `{clr:red}` сохранены
* UTF-8 корректен

##  Возможные проблемы

###  "No translation was found"

→ временная ошибка API
→ запусти повторно с меньшей скоростью

---

###  ошибки при больших workers

→ уменьшить:

```text
--workers 5
```

---

###  кривой текст в консоли

→ это проблема кодировки PowerShell
→ файл остаётся нормальным
