# Инструкция по автоматическому переводчику FGG

Эта инструкция относится к файлу:

```text
D:\FGG\final_translator.py
```

Он сохраняет структуру файла:

```text
ключ = "текст"
```

Также он старается не ломать игровые плейсхолдеры:

```text
{clr:red}
{clr/}
```

Например строка:

```text
test_line = "Закройте {clr:red}дверь{clr/}"
```

после перевода останется в таком же формате:

```text
test_line = "Schließen Sie {clr:red}Tür{clr/}"
```

## Где лежат файлы

Основная папка:

```text
D:\FGG
```

Основной скрипт:

```text
D:\FGG\final_translator.py
```

Русский исходный файл:

```text
D:\FGG\оригинал\rus.txt
```

Папка обычных переводов:

```text
D:\FGG\переводы
```

Тестовый файл на 1000 строк:

```text
D:\FGG\оригинал\test_1000_ru.txt
```

Папку для тестовых переводов лучше использовать отдельную:

```text
D:\FGG\переводы_тест
```

## Самый простой запуск

Открой командную строку или PowerShell и выполни:

```powershell
python D:\FGG\final_translator.py --langs de
```

Это переведёт русский файл:

```text
D:\FGG\оригинал\rus.txt
```

в немецкий файл:

```text
D:\FGG\переводы\de.txt
```

Если файл `de.txt` уже существует, переводчик попробует использовать уже готовые переводы и не переводить их заново.

## Быстрый запуск для немецкого

Хорошая быстрая команда:

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

Что это значит:

```text
--langs de
```

переводить только немецкий.

```text
--workers 10
```

делать до 10 параллельных переводов одновременно.

```text
--request-delay 0
```

не делать дополнительную паузу после каждого запроса.

Если у тебя с этой командой нет ошибок, это хороший режим для быстрого перевода.

## Максимально быстрый режим

Можно попробовать ещё быстрее:

```powershell
python D:\FGG\final_translator.py --langs de --workers 15 --request-delay 0 --max-retries 2 --retry-delay 1
```

Этот режим агрессивнее.

Что меняется:

```text
--workers 15
```

одновременно работает 15 потоков.

```text
--max-retries 2
```

если строка не перевелась, скрипт пробует только 2 раза.

```text
--retry-delay 1
```

между повторными попытками ждёт меньше.

Такой режим быстрее, но если начнёт отдавать ошибки, лучше вернуться к:

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

или:

```powershell
python D:\FGG\final_translator.py --langs de --workers 5 --request-delay 0.3
```

## Когда использовать --force

Параметр:

```text
--force
```

заставляет переводчик переводить всё заново, даже если в выходном файле уже есть готовые строки.

Используй `--force`, если хочешь полностью перегенерировать перевод:

```powershell
python D:\FGG\final_translator.py --langs de --force --workers 10 --request-delay 0
```

Не используй `--force`, если перевод был остановлен и нужно продолжить.

Правильно для продолжения:

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

Неправильно для продолжения:

```powershell
python D:\FGG\final_translator.py --langs de --force --workers 10 --request-delay 0
```

Потому что `--force` снова начнёт переводить уже готовые строки.

## Как продолжить после остановки

Если ты нажал `Ctrl+C`, скрипт сохранит уже переведённые строки.

После этого просто запусти снова без `--force`:

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

Скрипт прочитает:

```text
D:\FGG\переводы\de.txt
```

и пропустит строки, которые уже отличаются от русского оригинала.

## Файл .failed.txt

Если часть строк не перевелась, рядом с переводом появится файл:

```text
D:\FGG\переводы\de.failed.txt
```

В нём список ключей, которые не удалось перевести.

Например:

```text
test_line_0042
test_line_0137
```

Это не катастрофа.

Обычно достаточно запустить перевод ещё раз без `--force`:

```powershell
python D:\FGG\final_translator.py --langs de --workers 5 --request-delay 0.5
```

Почему медленнее:

иногда не любит слишком много запросов подряд. Повторный запуск с меньшей скоростью часто спокойно добивает оставшиеся строки.

Если после успешного перевода ошибок нет, файл `.failed.txt` удалится автоматически.

## Тестовый файл на 1000 строк

Для проверки скорости и стабильности создан файл:

```text
D:\FGG\оригинал\test_1000_ru.txt
```

В нём 1000 переводимых строк:

```text
test_line_0001
test_line_0002
...
test_line_1000
```

Запуск тестового перевода:

```powershell
python D:\FGG\final_translator.py --langs de --input D:\FGG\оригинал\test_1000_ru.txt --output-dir D:\FGG\переводы_тест --force --workers 10 --request-delay 0
```

Результат будет здесь:

```text
D:\FGG\переводы_тест\de.txt
```

Если хочешь проверить более жёсткий режим:

```powershell
python D:\FGG\final_translator.py --langs de --input D:\FGG\оригинал\test_1000_ru.txt --output-dir D:\FGG\переводы_тест --force --workers 15 --request-delay 0 --max-retries 2 --retry-delay 1
```

## Что означают основные параметры

### --langs

Выбирает языки.

Пример:

```powershell
--langs de
```

или:

```powershell
--langs de en fr
```

### --input

Указывает исходный русский файл.

Пример:

```powershell
--input D:\FGG\оригинал\rus.txt
```

Для теста:

```powershell
--input D:\FGG\оригинал\test_1000_ru.txt
```

### --output-dir

Указывает папку, куда сохранять переводы.

Пример:

```powershell
--output-dir D:\FGG\переводы
```

Для теста:

```powershell
--output-dir D:\FGG\переводы_тест
```

### --force

Переводит всё заново.

Нужен, если хочешь полностью перезаписать перевод.

Не нужен, если хочешь продолжить после остановки.

### --workers

Количество параллельных потоков.

Осторожно:

```text
--workers 3
```

Быстро:

```text
--workers 10
```

Очень быстро:

```text
--workers 15
```

Если появляются ошибки, уменьши `--workers`.

### --request-delay

Пауза после запроса.

Максимальная скорость:

```text
--request-delay 0
```

Более спокойно:

```text
--request-delay 0.3
```

Очень надёжно:

```text
--request-delay 1
```

### --max-retries

Сколько раз повторять перевод строки при ошибке.

Быстрее:

```text
--max-retries 2
```

Надёжнее:

```text
--max-retries 4
```

### --retry-delay

Пауза между повторными попытками.

Быстро:

```text
--retry-delay 1
```

Спокойно:

```text
--retry-delay 4
```

## Как понять, что всё хорошо

В консоли должно быть примерно так:

```text
[PROGRESS] 20/1000 новых, 0 взято из готового файла, ошибок: 0
[PROGRESS] 40/1000 новых, 0 взято из готового файла, ошибок: 0
...
[DONE] Новых переводов: 1000
[DONE] Использовано готовых: 0
[SUCCESS] Все выбранные языки переведены без ошибок
```

Если ошибок немного, это нормально.

Если ошибок много, уменьши скорость:

```powershell
python D:\FGG\final_translator.py --langs de --workers 5 --request-delay 0.5
```

## Как проверить результат

Открой файл:

```text
D:\FGG\переводы\de.txt
```

или для теста:

```text
D:\FGG\переводы_тест\de.txt
```

Проверь:

1. `lang = "de"`
2. `lang_name = "DEUTSCH"`
3. строки реально на немецком;
4. ключи слева не изменились;
5. плейсхолдеры `{clr:red}` и `{clr/}` остались внутри строк.

Пример хорошей строки:

```text
test_line_0002 = "Nachricht 2: Schließen Sie {clr:red}Tür{clr/}, wenn Sie Geräusche im Flur hören."
```

Пример плохой строки:

```text
test_line_0002 = "Сообщение 2: закройте {clr:red}дверь{clr/}, если услышите шум в коридоре."
```

Плохая строка означает, что она не была переведена. Запусти скрипт повторно без `--force`.

## Важное про кодировку

Иногда PowerShell может показывать немецкие символы некрасиво:

```text
SchlieГџen
TГјr
```

Это не всегда значит, что файл испорчен.

Чаще всего это проблема отображения в консоли.

Сам файл сохраняется в UTF-8.

Чтобы проверить нормально, открой файл в редакторе, который понимает UTF-8.

## Если перевод завис или хочется остановить

Нажми:

```text
Ctrl+C
```

Скрипт должен написать:

```text
[STOP] Остановлено пользователем, сохраняю готовые строки...
```

После этого уже готовые строки будут сохранены.

Потом продолжай без `--force`:

```powershell
python D:\FGG\final_translator.py --langs de --workers 10 --request-delay 0
```

## Если выдаёт No translation was found

Иногда в консоли может быть:

```text
No translation was found
```

Обычно это временная проблема конкретного запроса.

Что делать:

1. Дождаться конца.
2. Посмотреть, появился ли `de.failed.txt`.
3. Запустить повторно медленнее и без `--force`.

Команда:

```powershell
python D:\FGG\final_translator.py --langs de --workers 5 --request-delay 0.5
```
